This guide walks you through launching DeepSeek Harness for the first time. You'll start the Web UI, connect a model, and send your first task to an AI agent—all in under five minutes. No global installation is required; `npx` handles everything.

## Run from npm

<Steps>
  <Step title="Check Prerequisites">
    DeepSeek Harness requires **Node.js 22.19 or later**, or **Node.js 24+**. Check your version:

    ```sh
    node --version
    ```

    If you need to install or upgrade Node.js, visit [nodejs.org](https://nodejs.org) or use a version manager such as [nvm](https://github.com/nvm-sh/nvm) or [fnm](https://github.com/Schniz/fnm).
  </Step>

  <Step title="Start the Web UI">
    Launch the DeepSeek Harness Web UI with a single command. No prior installation step is needed—`npx` downloads and runs the package automatically.

    <CodeGroup>
      ```sh npx
      npx @deepseek-ai/dsh web
      ```
    </CodeGroup>

    The Web UI starts and is served at **http://127.0.0.1:3080** by default. Open that address in your browser.

    <Note>
      The first run may take a moment as `npx` downloads the package. Subsequent runs use the cached version and start faster.
    </Note>
  </Step>

  <Step title="Configure a Model">
    Before running any tasks, you need to connect a model provider.

    1. In the Web UI, open **Settings → Models**.
    2. Enter your **DeepSeek API key** in the credentials field.
    3. Save the settings.

    <Note>
      Your API key can also be provided via the `DEEPSEEK_API_KEY` environment variable or a `.env` file in your working directory—see the note at the bottom of this page.
    </Note>
  </Step>

  <Step title="Choose a Workspace Directory">
    The agent operates relative to a **workspace directory**—the directory the `dsh` process was started from becomes the default workspace root.

    Start `dsh` from the directory you want the agent to work in:

    ```sh
    cd /path/to/your/project
    npx @deepseek-ai/dsh web
    ```

    You can also set the workspace directory from within the Web UI after launch.
  </Step>

  <Step title="Run Your First Task">
    With a model configured and a workspace selected, type a prompt in the chat interface and press **Enter**. For example:

    ```
    Summarize this repository and identify its main packages.
    ```

    The agent will process the request, explore the workspace, and stream its response back to you in the Web UI.
  </Step>
</Steps>

## Run from Source

If you prefer to build and run from a repository checkout—for example, to contribute to `dsh` or test unreleased changes—follow these steps:

<Steps>
  <Step title="Clone the Repository">
    ```sh
    git clone https://github.com/deepseek-ai/deepseek-harness.git
    cd deepseek-harness
    ```
  </Step>

  <Step title="Install Dependencies">
    DeepSeek Harness uses [pnpm](https://pnpm.io) as its package manager.

    ```sh
    pnpm install
    ```
  </Step>

  <Step title="Build All Packages">
    ```sh
    pnpm run build
    ```

    This compiles TypeScript sources and builds the frontend artifacts required by the Web UI. Production runs require built artifacts; skip this step only if you are running in a development mode that handles this separately.
  </Step>

  <Step title="Start the Web UI">
    ```sh
    pnpm dsh web
    ```

    The Web UI is now available at **http://127.0.0.1:3080**.
  </Step>
</Steps>

## One-Shot Headless Usage

For scripting and automation, the `headless` profile runs a single session, prints the final answer to stdout, and exits. No server or browser is involved.

```sh
pnpm dsh --profile headless "summarize this workspace"
```

The invoking directory is used as the workspace root. The session is persisted to the Harness home so you can review it later.

<Tip>
  The `headless` profile is ideal for CI pipelines, batch tasks, and any scenario where you need the agent's output as part of a larger script.
</Tip>

## Setting Your API Key

<Note>
  `DEEPSEEK_API_KEY` must be available to the `dsh` process. You can provide it in one of two ways:

  **Environment variable:**
  ```sh
  export DEEPSEEK_API_KEY=sk-...
  npx @deepseek-ai/dsh web
  ```

  **`.env` file** in your working directory:
  ```sh
  # .env
  DEEPSEEK_API_KEY=sk-...
  ```
</Note>
