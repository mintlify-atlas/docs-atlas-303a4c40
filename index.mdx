DeepSeek Harness (`dsh`) is an open-source AI agent harness built by [DeepSeek AI](https://deepseek.com). Its architecture is built on a single principle: **everything is a plugin**. The model adapter, tool registry, session log, sandbox policy, and the agent loop itself are all Cordis plugins — every part is replaceable through configuration without patching any core.

## Key Features

- **Everything is a plugin** — swap the model adapter, tool registry, sandbox, or agent loop from configuration alone
- **Profiles and bundles** — composable layered configuration stacks for web, headless, and custom deployment shapes
- **Event-sourced session log** — append-only, durable source of truth for all model history and tool activity
- **Capability seams** — filesystem, shell, subprocess, sandbox, and LLM backends are all swappable behind stable interfaces
- **Code Mode** — the model can call registered tools programmatically via a generated TypeScript SDK
- **Python SDK** — drive agent sessions from Python over JSON-RPC without managing Node.js manually
